A warm Christmas-themed gift catalog. Browse playful “superpower” gifts in glass baubles, filter by category, open a detail modal, and watch the countdown to New Year.

App folder: `christmas-shop/` · Repo: [github.com/top-secret666/christmas-shop](https://github.com/top-secret666/christmas-shop)

## Features

- **Hero landing** — festive ornament, CTA, and holiday copy
- **Gift catalog** — card grid with 3D bauble art
- **Category filters** — All · For Work · For Health · For Harmony
- **Gift modal** — description + Live / Create / Love / Dream superpowers
- **New Year countdown** — days, hours, minutes, seconds
- **Responsive nav** — burger menu on mobile, scroll-to-top on gifts page
- **Smooth UX** — overlays, custom cursor accents, Montserrat + Allura fonts

## Quick start

No build step — pure static site.

```bash
git clone https://github.com/top-secret666/christmas-shop.git
cd christmas-shop/christmas-shop

# Python 3
python -m http.server 8765

# or Node
npx serve -l 8765
```

Open **http://127.0.0.1:8765/home.html**

| Page | File |
| --- | --- |
| Home | `home.html` |
| Gifts catalog | `gifts.html` |

## Structure

```text
christmas-shop/
├── home.html          # Landing: hero, about, best gifts, countdown, contacts
├── gifts.html         # Catalog with filters + modal
├── css/style.css      # Layout & festive theme
├── js/main.js         # Burger, modal, filters, countdown
└── assets/img/        # Baubles, Santa, icons, backgrounds
```

## Stack

| Layer | Choice |
| --- | --- |
| Markup | HTML5 (`home.html`, `gifts.html`) |
| Styles | CSS3 — flex/grid, responsive breakpoints |
| Logic | Vanilla JavaScript — modal, filters, countdown, burger |
| Fonts | [Montserrat](https://fonts.google.com/specimen/Montserrat) · [Allura](https://fonts.google.com/specimen/Allura) |
